# Retail Analytics Database Project

## Project Overview

This project is a Retail Analytics Database built using SQL Server.

The database manages customers, products, stores, and sales transactions. SQL queries are used to analyze sales performance, product demand, customer activity, and store-wise sales.

## Database Tables

- Customers
- Products
- Stores
- Sales

## SQL Concepts Used

- Primary Keys and Foreign Keys
- JOIN
- GROUP BY
- HAVING
- Subqueries
- Views
- Stored Procedures
- Triggers
- 3NF Normalization

## Project Structure

- `SQL` – Contains the SQL database script.
- `ER-Diagram` – Contains the database ER diagram.
- `Documentation` – Contains detailed project documentation.
